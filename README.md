# Reverend Coffee

Website for Reverend Coffee in Rubavu: Mahoko, and Gisenyi near Petite Barrière. Guests scan a QR code and open the digital menu on their phone.

## Run it

```bash
npm install
npm run dev
```

## Edit the menu, hours, and copy

All of that lives in `src/data/site.js`. Change a price or a dish there and both the website and the QR menu update together.

The printable table codes are on the **QR codes** page. Print them after the site is deployed, so each code points at the public address rather than your computer.
